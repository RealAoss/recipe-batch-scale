# Recipe Batch Scale

Scale ingredient quantities for a different number of servings and print a kitchen copy.

## Open the app

Download `index.html` and open it in a modern browser. Everything runs locally. Work stays in the tab until you close it.

## Example

Change a four-serving recipe to six servings. An ingredient measured at 1 1/2 cups becomes 2.25 cups. Amounts use up to four significant digits. Units stay as entered; cooking times are not scaled.

## Limitations

Work stays in the browser tab. Save the result before closing or refreshing the page.
